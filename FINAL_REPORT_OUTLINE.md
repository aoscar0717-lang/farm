# Capstone Final Report Outline

## 1. Game promise and player

- One-sentence player promise
- Intended player/problem
- Minimum playable loop

## 2. Scope and exclusions

- Required V3 behavior
- Features intentionally excluded
- Reason for the cut line

## 3. State model and contracts

- Important state fields
- Four key contracts
- One diagram or annotated screenshot

## 4. V0 to V3 development story

For every version, include its tag, screenshot, player-visible difference, engineering evidence, and remaining limitation.

## 5. Test design

- Six or more focused tests
- Boundary and invariant reasoning
- What the tests prove and do not prove

## 6. Debugging story

- Observed failure
- Contract expectation
- Smallest hypothesis and repair
- Focused and regression evidence

## 7. Human playtest and V3 decision

- Observed actions/comments
- Selected change and justification
- Repeat-check evidence

## 8. GitHub collaboration

- Branch/PR strategy
- Authored and reviewed work by each member
- One review decision that changed the project

## 9. AI use and human responsibility

- Material L1 uses
- Adopted, modified, and rejected suggestions
- Verification and limitations

## 10. Current release and next hypothesis

- Reproducible run instructions
- Known limitation
- Next small experiment, not a feature wish list

## Individual appendix

Each member writes:

- their authored contribution;
- one reviewed contribution;
- one contract/test they can explain;
- one unaided change they could make; and
- one lesson from the iteration cycle.
