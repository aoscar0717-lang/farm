# 🌾《夜巡農場》(Nightwatch Farm) - 2D 網格塔防經營遊戲

歡迎來到《夜巡農場》！這是一款結合「中央農田經營耕作」與「四周景觀佈置塔防守衛」的日夜循環策略遊戲。

---

## 🎮 遊戲快速啟動方式 (Quick Start)

### 1. 安裝環境依賴 (Dependencies)
請確保本機已安裝 Python 3.10+，並在終端機安裝 Pygame：

```bash
pip install -r requirements.txt
```

### 2. 啟動遊戲 (Run Game)
直接執行入口主程式：

```bash
python main.py
```
或
```bash
python advanced_nightwatch_farm-v3.py
```

### 3. 執行單元測試 (Run Tests)
驗證底層遊戲邏輯（種植、收成、金庫掠奪、日夜破曉與破產判定）：

```bash
python test_game_engine.py
```

## 🌟 核心特色與玩法機制

1. **🌾 中央高架農田（賺錢經營）**
   - 包含 10 種多樣化作物（蘿蔔、番茄、玉米、茄子、草莓、南瓜、西瓜、向日葵、紫葡萄、星光果）。
   - **成熟作物直接點擊即可採收換金**，無須手動切換工具！
   - 白天可用「黃金澆水壺」加速生長 50%。

2. **🌸 四周莊園景觀（解鎖升級）**
   - 自由建造 13 種景觀（松柏樹、蘋果樹、長椅、櫻花樹、噴泉、日晷、風車等）。
   - 景觀提供永久「繁榮度」，達到指定分數自動升級農場（Lv.1 ~ Lv.5 傳奇仙境），解鎖更高利潤種子！

3. **🌙 夜晚守衛與防偷懶金庫機制**
   - **中央金庫防禦**：若夜晚田裡空無一物（試圖掛機避戰），入侵者將直接突襲中央金庫，掠奪 35% 總資金！
   - **月光滋養加成**：成功守護作物過夜，隔日早晨採收可享 **+50% 巨額額外金幣**！
   - **血月首領戰**：第 3 天起夜晚將降臨超高血量「野豬暴君 Boss (600 HP)」。

4. **🛡️ 塔防設施與戰術工具**
   - **刺藤木柵**：唯一實體阻擋障礙物，可引導敵人尋路路線，並附帶每秒 12 點刺藤尖刺反傷！
   - **鋼鐵捕獸夾**：踩踏造成 120 點爆發傷害。
   - **蜜蜂守衛巢**：自動向範圍內敵人發射蜂針遠程射擊。
   - **看門柴犬 & 招財小貓**：柴犬夜間主動撲咬追擊（可吹哨指揮），小貓白天定時巡邏贈金。
   - **🔦 3 秒強光手電筒**：夜晚點擊照暈敵人 2.5 秒（每 3 秒快速充能一次）。

## 📁 專案檔案結構

```
nightwatch_farm/
├── assets/                       # 所有純色透明 PNG 素材
│   ├── crops/                   # 10 種農作物 (各4階段生長圖)
│   ├── decorations/             # 13 種莊園景觀設施圖
│   ├── defenses/                # 木柵、捕獸夾、稻草人、蜂巢、水壺
│   └── characters/              # 柴犬、招財貓、小偷、野豬、蝙蝠、血月Boss
├── game_config.py               # 數值平衡、等級、實體資料結構與事件定義
├── game_state.py                # 遊戲核心狀態機、尋路、戰鬥與日夜邏輯 (無渲染)
├── sound_manager.py             # 現代合成音效管理器
├── asset_loader.py              # 透明 PNG 圖檔載入器
├── generate_assets.py           # 向量圖檔生成腳本
├── advanced_nightwatch_farm-v3.py # Pygame 完整渲染客戶端
├── main.py                      # 遊戲啟動入口
├── test_game_engine.py          # 單元測試套件
├── requirements.txt             # 依賴套件 (pygame)
├── ASSET_REPLACEMENT_GUIDE.md   # 組員素材替換指南
└── README.md                    # 本專案說明文件
```
