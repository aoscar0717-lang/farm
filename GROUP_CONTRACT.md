## Conflict and recovery protocol

1. Pause the merge.
2. Restate the relevant contract in one sentence.
3. Write the observation that would distinguish the options.
4. Run the smallest useful check.
5. Record the decision and reason.
6. Ask for help if evidence remains ambiguous.
